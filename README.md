# Sarah Samia & Shadaat Hanif — Cinematic Digital Wedding Invitation

A royal cinematic digital wedding invitation featuring a custom 3D physical door-opening animation revealing the historic **Safed Baradari** in Lucknow, accompanied by continuous looped instrumental flute BGM (*Jashn-E-Bahaaraa*).

## ✨ Features
- **Cinematic Door Opening**: Interactive tap-to-open sequence with matched initial/final frame synchronization.
- **Historic Venue View**: Grand architectural entrance opening directly into the illuminated hall of Safed Baradari, Lucknow.
- **Royal Mughal Aesthetic**: Gold and white palace theme with Arabic calligraphy (`بِسْمِ اللَّهِ الرَّحْمَٰنِ الرَّحِيمِ`) and Surah Ar-Rum [30:21].
- **Interactive Scratch Card**: Scratch-to-reveal wedding date card with quick-reveal toggle.
- **Live Countdown**: Accurate countdown to November 30, 2026, 8:00 PM IST.
- **Background Music**: Looped 30-second flute instrumental with native HTML5 audio and YouTube/Web Audio fallback.
- **Wedding Itinerary**: Detailed timeline (Baraat & Istiqbaal, Nikah Ceremony, Royal Dastarkhwan).
- **Google Maps Integration**: Venue location modal linking directly to Safed Baradari on Google Maps.
- **Calendar Export**: One-click Apple/Google/Outlook `.ics` calendar invite generator.

## 🚀 Deployment
Deploy instantly to [Vercel](https://vercel.com) or [Cloudflare Pages](https://pages.cloudflare.com):
- Framework preset: `Other` / Static HTML
- Build command: None (pure vanilla HTML/CSS/JS)
- Output directory: `./`
